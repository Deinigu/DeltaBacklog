# Contributing

DeltaBacklog is a personal project, shared so people can see the code and use it if it is useful to them. **It is not accepting contributions**: no pull requests, no feature requests, no bug-report triage.

## What to do instead

- **Fork it.** The code is [MIT licensed](LICENSE): fork, change, reuse and self-host it however you like. To build and test a fork, see [section 3 of the developer manual](docs/developer-manual.md#3-running-it) (running it, the checks CI runs, the demo library).
- **Ask yourself if you need my permission.** You do not.

## Why

It is built for one person's library on one Raspberry Pi, and its scope is deliberate (no ratings, no login, light on memory). Keeping that small and coherent is easier without reviewing outside changes, and this is a spare-time project.

## What to expect

- Unsolicited pull requests and issues may be closed without comment. Nothing personal.
- There is no support and no response-time promise.
- **Security reports are the one exception.** Report them privately, as described in [SECURITY.md](SECURITY.md), never as a public issue or pull request.
